## High-Value Findings

1. The training set has 773 wells, 5,092,255 horizontal rows, and 3,783,989 hidden/evaluation rows. Every train `TVT_input` mask is a suffix, matching the competition setup.
2. The visible local test set has only 3 wells, and those three files are exact visible-column copies of train wells. Use them for submission plumbing only, not validation.
3. The hidden interval is large: median 4,840 rows per well and median 74.0% of each horizontal well.
4. `TVT - last_known_TVT` is centered near zero but has material tails. End-of-hidden delta median is 1.40 ft, 5th percentile is -31.43 ft, 95th percentile is 32.16 ft, and max absolute hidden delta is 103.78 ft.
5. A constant-last-known baseline is surprisingly strong: row RMSE 15.91 across all hidden train rows. Raw prefix-slope extrapolation is unsafe: prefix-step100 row RMSE is 116.36, with catastrophic per-well failures.
6. GR is frequently missing in the evaluation zone: median hidden missing rate is 30.3%, 95th percentile is 64.1%, and the 95th percentile longest missing run is 144 rows.
7. Typewell correlation is real but noisy. Known-prefix GR-vs-typewell RMSE median is 13.67 API, hidden oracle alignment RMSE median is 10.55 API, and their per-well correlation is 0.454.
8. Typewell `Geology` labels are available in test-time files and cover 66.6% of all typewell rows. Main labels are `ANCC`, `EGFDL`, `ASTNL`, `BUDA`, `ASTNU`, and `EGFDU`.
9. Train-only formation surface columns are not available in visible test horizontal files. Do not add direct features from `ANCC/ASTNU/ASTNL/EGFDU/EGFDL/BUDA` unless they are used only for training diagnostics or distilled into test-available features.
10. Beam path matching was evaluated on a deterministic 97-well sample. It is not good enough as a standalone predictor, but it is competitive at the first 15% of the hidden interval and then degrades. This supports using beam features with reliability gates, not replacing the model with beam output.
11. The host PPTX emphasizes that TVT can increase, decrease, or stay constant. This independently confirms that hard monotonic post-processing would be unsafe.
12. The host PPTX says horizontal GR before Prediction Start may correlate better with the post-PS lateral than typewell GR. This supports adding self-correlation/template features from the known prefix.
13. The host PPTX says azimuth and offset wells can matter. Train EDA partly supports this as a feature family, but not as a standalone prior: nearest PS neighbors are close and nearly parallel, yet nearest-neighbor end-delta correlation is only 0.124.
